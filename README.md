
# IT Infrastructure Health Checker

## Overview
A PowerShell-based tool developed to perform basic Windows infrastructure health checks and generate reports.

## Features
- Collects system information.
- Checks CPU and memory utilisation.
- Monitors available disk space.
- Checks Windows services.
- Tests network connectivity.
- Exports results into a CSV report.
- Provides basic warning and error logging.

## Technologies
- Windows PowerShell 5.1
- Windows system administration
- CSV reporting

## How to Run

1. Download or clone this repository.
2. Open PowerShell.
3. Navigate to the project folder.
4. Run the script:

```powershell
.\HealthChecker.ps1
```

If script execution is blocked, review your PowerShell execution policy before running it.

## Purpose
This project was developed as a practical learning exercise to improve PowerShell scripting, infrastructure monitoring and IT automation skills.
